GeoGenesis 的使命是构建一个面向地球科学学生的知识共享与经验流动平台，打破信息不对称。

## 我们做什么

- **访谈**：记录前辈的研究路径与实践经验
- **课程整理**：将零散笔记结构化为可复用的学习资料
- **项目实践**：通过小型科研协作积累真实经验
- **社区建设**：连接每一届成员，让知识可持续流转

### 四大板块

| 板块 | 说明 |
|------|------|
| 文档 | 长篇资料、课程笔记与研究导读 |
| 动态 | 组织公告与社区进展 |
| 活动 | 讲座、工作坊与讨论会 |
| 关于 | 使命、愿景与参与方式 |

## 如何使用本站

### 阅读文档

文档板块采用**三栏布局**：左侧为文档导航，中间为正文，右侧为本页目录。适合阅读结构化、篇幅较长的资料。

### 关注动态与活动

动态板块发布阶段性公告；活动板块列出即将进行的社区活动。

### 参与贡献

组织尚在早期建设阶段。欢迎通过 GitHub 仓库提交文档改进建议或内容贡献。

## 常见问题

### 我是新生，从哪里开始？

建议先阅读本页，再浏览「入门指南」分类下的文档，最后查看活动板块。

### 文档与动态有什么区别？

文档侧重**长期可用的知识沉淀**；动态侧重**时效性信息与公告**。

本站框架与视觉仍在迭代，感谢你的耐心与支持。
